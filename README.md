# JPG File Organizer

## Description
JPG File Organizer is a Python automation project that automatically moves JPG image files from one folder to another.

## Features
- Automatically finds JPG files.
- Creates a destination folder if needed.
- Moves images automatically.
- Saves time and reduces manual work.

## Technologies Used
- Python
- OS module
- Shutil module

## How to Run
1. Install Python.
2. Open `jpg_file_organizer.py`.
3. Run the program.
4. Enter the source folder path.
5. Enter the destination folder path.

## Concepts Used
File Handling, Functions, Loops, OS and Shutil.
